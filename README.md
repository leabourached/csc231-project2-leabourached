# csc231-project2-leabourached



**game aesthetic**



* game title: Fern \& the fading flame
* main original character (player): Fern, a red fox.
* environment: forest, night setting
* enemies: wandering spirits
* storyline/backstory:

Fern is a young red fox from a long line of forest guardians. His ancestors built shrines throughout the forest, each lit by a pyrka, a tiny fire spirit that keeps the evil spirits away. But something scared the pyrkas off into the night, and the shrines went dark. Now Fern must travel through the forest, gather the lost pyrkas, and return them to their shrines before dawn.





signature move: double jump

attack: lantern swing, also relights the shrine candles

collectibles: Pyrkas (fire spirits Greek "pyr" for fire)

checkpoint: shrines fern relights, a final bigger shrine ends the level

hazards: thorns \& the spirits ( double jump to get away from the thorns and the attack the spirits).
